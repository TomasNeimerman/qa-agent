<objective>
Close CR-01, the one code gap 05-VERIFICATION.md found: the `--smoke` branch of
`scripts/test-case-doc.mjs` selects cases without ever scanning them for
`FORBIDDEN_DISPATCH_FLAGS`, so a hand-edited document carrying `--confirmed` or
`--allow-non-local` exits 0 on the smoke path while the same document exits 9 on a plain
validate run. The `## Smoke-test protocol` hands its set to `## Running generated cases`
steps 4-6, skipping that section's step 3 — the place the scan otherwise happens — so today
nothing on the smoke path ever scans the cases it is about to dispatch.

Purpose: plan 05-01's first prohibition and its T-05-01 mitigation both assert that the
`FORBIDDEN_DISPATCH_FLAGS` refusal "still stands between a smoke case and a destructive
call". On the smoke path that sentence is currently false. This plan makes it true and locks
it with tests, so REP-03 can close on something mechanical rather than on prose.

Output: a validation gate in the `--smoke` CLI branch, CLI regression tests reproducing the
verifier's own repro in both directions, and one new numbered step in `SKILL.md`'s
`## Smoke-test protocol` stating that the scan runs before dispatch.

**Phase goal (verbatim from ROADMAP.md):** The agent supports a fast post-deploy smoke check
and is packaged so any teammate can install it and run it unmodified against any of the
team's projects.
</objective>
