<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer-supplied base URL → outbound HTTP | An arbitrary host string becomes real network traffic sent with the test user's bearer token attached |
| target app response → report artifact | Untrusted response bodies and headers are parsed and persisted |
| shell environment → dispatch | Missing or wrong credentials silently change what the run means |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-16 | Elevation of Privilege | outbound request to a developer-supplied base URL (SSRF-adjacent) | high | mitigate | `looksLikeProduction()` refuses any host that is not recognisably local, private-range or a named non-production environment; proceeding requires an explicit per-run `--allow-non-local` flag, and the check runs before the token is even read |
| T-01-17 | Information Disclosure | bearer token sent to an unintended host | high | mitigate | The production-target check and `preflight` both run before `readConfig` resolves the credential, so a refused or unreachable target never causes the token to be loaded, let alone transmitted |
| T-01-18 | Spoofing | misleading 401 storm masking a configuration error | medium | mitigate | Missing token or base URL exits 2 with a specific message before dispatch; a real 401 or 403 response appends a status-derived hint to the verdict pointing at `QA_AGENT_TOKEN` rather than at the application |
| T-01-19 | Information Disclosure | `set-cookie` and other credential-bearing response headers persisted into the report | medium | mitigate | `evidence.response.headers` is passed through `redactHeaders` before storage, using the same allow-list of credential header names as the request path |
| T-01-20 | Tampering | method dispatch via dynamic property lookup on the Playwright context | medium | mitigate | An explicit `DISPATCH` map is the only way a method reaches the context; an unmapped method throws before any network activity |
| T-01-21 | Denial of Service | a hung target stalling the run indefinitely | low | mitigate | `preflight` uses a short timeout and fails fast to exit 4 rather than letting the run block on an unresponsive host |
</threat_model>
