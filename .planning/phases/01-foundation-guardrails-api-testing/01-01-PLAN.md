<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell env → skill script | `QA_AGENT_TOKEN` crosses from the developer's shell into `api-client.mjs`; it must not cross onward into the LLM context or the filesystem |
| skill script → target app | Arbitrary developer-supplied base URL is dialled over HTTP; the target may be localhost or a remote staging host |
| skill script → target repo filesystem | The skill writes report artifacts into a repo it does not own |
| npm registry → local machine | Third-party packages are installed and executed with full user privileges |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `scripts/api-client.mjs` evidence capture | high | mitigate | `redactHeaders()` replaces authorization/cookie/x-api-key/proxy-authorization values with `[REDACTED]` before the case object is returned, printed or written; the e2e test asserts the fixture token value is absent from stdout, results.json and the Markdown report |
| T-01-02 | Information Disclosure | `qa-reports/` inside the target repo | medium | mitigate | `format-report.mjs` writes `qa-reports/.gitignore` containing `*` on directory creation, so run evidence cannot be committed to the target project by accident |
| T-01-03 | Repudiation | `scripts/format-report.mjs` | high | mitigate | The formatter reads `results.json` only — never the conversation — and throws `EvidenceMissingError` for any `passed`/`failed` case lacking `evidence.response`, making an evidence-free verdict unrenderable (SAFE-03) |
| T-01-04 | Spoofing | env var resolution | medium | mitigate | Missing/empty `QA_AGENT_TOKEN` exits 2 with a specific configuration message instead of dispatching an empty `Authorization` header that would return misleading 401s (D-09) |
| T-01-SC | Tampering | npm installs (`playwright`, `zod`, `dotenv`, `vitest`) | high | mitigate | Package-legitimacy gate from RESEARCH.md plus the blocking human checkpoint in Task 1 for the `SUS`-flagged `playwright`; `@playwright/test` is deliberately not installed |
| T-01-05 | Information Disclosure | `dotenv` loading the target project's `.env.local` | medium | accept | Loading a target project's own env file is the documented fallback in RESEARCH `## Standard Stack`; values are read into the script process only, never echoed, and `override: false` prevents a repo file from shadowing an explicitly exported token |
