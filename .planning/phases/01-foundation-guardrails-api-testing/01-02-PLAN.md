<objective>
Install the safety guardrail that governs the whole project, before the client can send anything more dangerous than a GET. Two enforcement layers: (1) `api-client.mjs` mechanically refuses to dispatch a destructive method unless that specific invocation carries `--confirmed`, exiting 3 with a preview payload instead; (2) a `PreToolUse` hook matches any destructive `api-client.mjs` Bash invocation — including ones that already carry `--confirmed` — and escalates it to Claude Code's own permission dialog, which the hooks documentation states cannot be bypassed even under `--dangerously-skip-permissions`.

Purpose: RESEARCH.md and the project's own PITFALLS.md both call out retrofitting a guardrail after the agent already has broad access as materially riskier than building it in first. This plan lands the gate while the client can still only send GET, so there is never a window in which a DELETE-capable client exists ungated.

Output: a unit-tested classifier, a gated dispatcher, a hook backstop, the judgment rubric the orchestrator applies, and the third `blocked` result state that the report renderer consumes.

Implements D-01 (method-based detection, DELETE always), D-02 (no absolute blacklist — confirmation always unlocks), D-03 (pause at the exact point, show method/URL/body, wait for yes/no), D-04 (decline skips only that case and the run continues).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| orchestrator (LLM) → api-client script | The LLM decides which calls to make and could pass `--confirmed` without having paused; the script and the hook must both police that boundary |
| Claude Code permission layer → Bash tool | `--dangerously-skip-permissions` can suppress ordinary tool prompts; the PreToolUse hook is the documented path that survives it |
| api-client script → target app | A mutating request causes irreversible state change in a real localhost or staging environment |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Tampering | `scripts/api-client.mjs` dispatch path | critical | mitigate | `requiresConfirmation()` is consulted on every invocation before the Playwright context is created; a destructive method without `--confirmed` exits 3 having sent nothing, and the unit tests assert zero requests reached the mock server |
