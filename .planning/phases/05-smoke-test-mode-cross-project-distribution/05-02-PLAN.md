## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| three external repos' source trees → `discover-schema.mjs` / `## Discovery protocol` | Untrusted source and migration text from other teams' repositories is read and parsed here |
| this skill → each target repo's working tree | A validation pass runs inside repositories other consoles are actively working in |
| each target repo's `.env.local` → the run's credential resolution | Real test-user credentials for three different projects are in scope |
| smoke set → live HTTP/browser dispatch against a running app | Real mutating requests can reach a real database |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-09 | Tampering | path traversal out of a target project root during discovery | medium | mitigate | `discover-schema.mjs`'s existing exit-8 refusal for a resolved path outside the project root is unchanged, and `## Discovery protocol` step 10's stay-inside-the-root rule (never follow a symlink out, never open a file outside the documented allowlist) is followed as written |
